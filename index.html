● Система работает в штатном режиме (Proxmox VE 9.2)

Боевой CI/CD Конвейер

Этот лендинг проверен автоматическими тестами на собственном сервере ci-runner и мгновенно доставлен по защищенному протоколу SSH на веб-сервер prod-server (Nginx).

Архитектура стенда

1. GitHub & Триггер

Хранилище исходного кода отслеживает каждый коммит в ветку main и мгновенно будит домашнего сборочного робота.

2. CI-Runner (CT 100)

Изолированный LXC-контейнер на Ubuntu 24.04 проверяет целостность верстки, ставит штамп релиза и блокирует ошибки.

3. Prod-Server (CT 101)

Боевой веб-сервер под управлением Nginx принимает сборку по ключу Ed25519 и отдает сайт на скорости локальной сети.
